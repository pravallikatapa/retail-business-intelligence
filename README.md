# Retail Business Intelligence Project

## Overview

An end-to-end retail sales analytics project using the Microsoft AdventureWorks sample dataset. The project transforms raw sales data into a relational star schema and an interactive Power BI dashboard to explore sales, profitability, product categories, and regional performance.

## Tools & Technologies

- Python — data cleaning, transformation, and validation
- MySQL — relational data storage, star schema, and SQL analysis
- Power BI — interactive dashboard and KPI visualization
- Excel — source dataset

## Project Workflow

Excel → Python → MySQL → Power BI → Business Insights

## Dashboard

The Power BI dashboard includes:

- Total Revenue, Total Cost, Total Profit, Profit Margin, and Units Sold KPIs
- Revenue trend by year
- Revenue by product category
- Revenue by region
- Top 10 products by revenue
- Year, category, and region slicers

## Key Business Findings

- Total Revenue: $109,809,274.20
- Total Product Cost: $97,257,907.95
- Total Profit: $12,551,366.25
- Overall Profit Margin: 11.43%
- Total Units Sold: 274,776
- Bikes contribute the largest share of revenue.
- Accessories have the highest category profit margin.
- Regional revenue and profitability vary considerably.

## Data Notes

The dataset covers July 2017 through June 2020. The year 2020 contains data only through June, so it is a partial-year period.

The SQL-ready `Sales_Fact_SQL.csv` file is intentionally excluded from version control because it is an intermediate import file generated by the Python export script.

## Repository Structure

- `Data/` — source dataset
- `Python/` — data inspection, cleaning, and transformation scripts
- `Cleaned_Data/` — cleaned dimension and fact tables
- `SQL/` — database setup, table creation, and analysis queries
- `Power BI/` — Power BI report
- `Documentation/` — project documentation

## How to Use

1. Review the Python scripts to understand the data preparation process.
2. Use the SQL scripts to create and analyze the database.
3. Open the `.pbix` file in Power BI Desktop to explore the dashboard.

## Disclaimer

This is a portfolio project using a sample dataset. Findings describe the data analyzed and should not be interpreted as current business performance.
